Root-Spector · Design System

Sistema de design da plataforma

Registro das decisões visuais tomadas na Fase 1: paleta, tipografia, espaçamento e componentes. Cobre as 3 superfícies que compartilham a mesma linguagem: o frontend do produto, o relatório HTML gerado pelo agente e os documentos técnicos desta pasta. Nenhuma dessas superfícies foi alterada para gerar este documento, ele só descreve o que já existe.

Onde esta linguagem visual aparece

As 3 superfícies usam os mesmos tokens de cor e tipografia, mas cada uma mantém sua própria folha de estilo (não há um pacote de CSS compartilhado entre elas hoje).

Princípios

  • Cores de status sempre em tom pastel. Nunca vermelho, amarelo ou verde saturados. Fundo claro com texto de contraste legível, mesmo par de cores em qualquer componente que precise indicar situação (aceitável, atenção, crítico, neutro).
  • 3 famílias tipográficas, cada uma com um papel fixo. Serifada para títulos, monoespaçada para rótulos/tags/código, sem serifa para o corpo do texto. Nunca usar a família errada para o papel errado.
  • Modo escuro automático, nunca manual. Todas as 3 superfícies usam @media (prefers-color-scheme: dark), sem botão de alternância. Segue a preferência do sistema operacional do usuário.
  • Superfícies elevadas com sombra suave. Cartões (.card) usam borda de 1px mais sombra difusa, nunca bordas grossas ou sombras duras.
  • Cantos arredondados em 2 tamanhos só. 10px para cartões e contêineres, 6px para elementos menores (botões, campos, alertas).

Pilha completa: serifada é Charter, "Iowan Old Style", "Palatino Linotype", Georgia, "Noto Serif", serif. Sem serifa é -apple-system, "Segoe UI", Roboto, Helvetica, Arial, sans-serif. Manutenção

Os tokens de cor e tipografia do produto vivem em frontend/src/styles/tokens.css. O relatório gerado (root_cause_agent/reports.py) e os documentos desta pasta mantêm sua própria cópia dos mesmos valores, sem importar um arquivo compartilhado. Ao mudar um token aqui, é preciso replicar a mudança nos 3 lugares para manter a consistência.
